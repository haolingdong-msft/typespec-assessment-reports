Operation replacement and action LRO headers omit required continuity detailsMissing rename linkage removes the generated method instead of modeling a versioned rename, while the untyped combined LRO headers do not explicitly preserve the action's logical final result.
Affected intents (1)

failed

Expected

A replacement operation should retain rename and shared-route continuity through versioning decorators, and an overridden ArmCombinedLroHeaders must set FinalResult to the action response type or void.

Evolving APIs — Versioning Decorators
Use @added to introduce operations, @removed to remove them, and @renamedFrom to rename operations in a specific version.
Documented TypeSpec example
@removed(Versions.v3) createOrUpdate is ArmResourceCreateOrReplaceAsync<Employee>;
Documented TypeSpec example
@renamedFrom(Versions.v3, "oldName") newName: string;
Evolving APIs — Converting an Operation from Synchronous to Asynchronous
When replacing an operation across versions, retain version continuity with @removed, @renamedFrom, @sharedRoute, and @added on the old and new declarations.
Documented TypeSpec example
@removed(Versions.v2) @renamedFrom(Versions.v2, "createOrUpdate") @sharedRoute createOrUpdateV1 is ArmResourceCreateOrReplaceSync<Employee>;
Documented TypeSpec example
@added(Versions.v2) @sharedRoute createOrUpdate is ArmResourceCreateOrReplaceAsync<Employee>;
ARM long-running operations — Resource Action (POST)
ArmResourceActionAsync uses ArmLroLocationHeader by default, and FinalResult should match the action response type. When overriding with ArmCombinedLroHeaders, set FinalResult to the response type; use void for no-content actions.
Documented TypeSpec example
LroHeaders = ArmCombinedLroHeaders<FinalResult = MigrationResponse> & Azure.Core.Foundations.RetryAfterHeader
Documented TypeSpec example
LroHeaders = ArmCombinedLroHeaders<FinalResult = void> & Azure.Core.Foundations.RetryAfterHeader

Actual

The private endpoint update operation is removed and updateStatus is added without @renamedFrom or @sharedRoute. The cluster actions return ArmResponse<HorizonDbCluster> while overriding ArmCombinedLroHeaders without an explicit FinalResult.
