Expected

ARM PATCH guidance recommends a specific PATCH model with ArmCustomPatch* and explicitly says ArmResourcePatch* is not recommended because its visibility analysis is not replicated in generated SDKs.

ARM resource operations — Resource Update Operations (PATCH)
The ArmResourcePatch* templates are not recommended. They rely on Lifecycle.Update visibility analysis to automatically determine which properties are included in the PATCH schema, but this analysis is only performed by the typespec-autorest emitter and will not be replicated in SDKs generated for the PATCH operation. Instead, spec authors should define a specific PATCH model and use the ArmCustomPatch* templates.
