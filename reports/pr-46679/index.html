Expected

Use an explicit PATCH request model with ArmCustomPatchAsync so the REST and generated SDK request contract are intentional and consistent.

ARM resource operations — Resource Update Operations (PATCH)
The ArmResourcePatch* templates are not recommended. Their Lifecycle.Update analysis is performed by typespec-autorest and will not be replicated in SDKs; define a specific PATCH model and use ArmCustomPatch* templates.
Documented TypeSpec example
update is ArmCustomPatchAsync<ResourceType, PatchRequestModel>;
Azure.ResourceManager interface reference — ExtensionResourceInstanceOperations.update
The standard extension-resource update signature accepts Azure.ResourceManager.Foundations.ResourceUpdateModel<Resource, Properties> as the PATCH properties parameter.
Documented TypeSpec example
update(..., properties: Azure.ResourceManager.Foundations.ResourceUpdateModel<Resource, Properties>)
