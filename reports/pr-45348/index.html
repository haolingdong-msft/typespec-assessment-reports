Creating a new version of an existing common type involves adding the new version and exposing definitions for that version with @@armCommonDefinition.

Evolving APIs — Declaring Versions
Versioning allows an API to evolve without breaking existing clients. For each version, specify dependencies and common types as needed, and use versioning decorators for API changes.
Documented TypeSpec example
Declare @armCommonTypesVersion on each Versions enum member and evolve later API shapes with versioning decorators.
Versioning overview — How Versioning Works in TypeSpec
TypeSpec models changes in each new API version and works best when APIs evolve according to versioning guidelines without breaking changes.
